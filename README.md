# Web SSH IDE (Node.js + WebSockets)

Современная, быстрая и легкая веб-среда разработки (IDE) со встроенным интерактивным терминалом и файловым менеджером. Позволяет удаленно подключаться к серверам по протоколу SSH/SFTP, редактировать код в реальном времени и управлять файловой системой через удобный веб-интерфейс.

Проект построен на **асинхронной архитектуре на базе WebSockets (Socket.io)**, что обеспечивает мгновенный отклик терминала, экономию сетевого трафика и надежную поддержку многопользовательского режима без блокировки сервера.

---

## 🚀 Основные возможности

* **Интерактивный WebSocket-терминал:** Полноценный эмулятор PTY (на базе `Xterm.js`), работающий с минимальным пингом. Поддерживает динамический ресайз окна, цвета, интерактивные утилиты (`top`, `htop`, `nano`) и горячие клавиши.
* **Плавающее окно терминала:** Терминал не сжимает редактор, а открывается в виде модального оверлей-окна поверх него. Его можно перетаскивать мышкой за заголовок, менять его размер (resize) или полностью скрывать с экрана.
* **Удаленный файловый менеджер (SFTP):** Изолированный проводник для навигации по каталогам сервера. Поддерживает создание файлов/папок, их переименование и безвозвратное удаление прямо из веб-панели.
* **Редактор кода:** Полноразмерная зона для работы с кодом. Открытие файлов по двойному клику и быстрое сохранение изменений обратно на сервер.
* **Многопользовательская безопасность:** Асинхронный бэкенд на Node.js изолирует сессию каждого подключенного пользователя по его уникальному WebSocket ID. Пользователи не влияют на процессы друг друга.

```text

├── 📄 server.js              # Node.js бэкенд (SSH/SFTP сессии, логика WebSockets)
├── 📄 package.json           # Манифест проекта и управление зависимостями

```



## 🛠️ Как запустить проект у себя на компьютере

Для работы проекта вам понадобится установленный **Node.js** (рекомендуется версия LTS).

### 1. Клонирование и подготовка папки
Создайте на компьютере папку проекта `web-ssh-ide`, перенесите в неё файлы согласно структуре и откройте в ней терминал.

### 2. Установка зависимостей
Инициализируйте проект и установите три необходимые библиотеки (Express для сервера, Socket.io для вебсокетов и SSH2 для связи с серверами) одной командой:

```bash
npm init -y && npm install express socket.io ssh2
```

### 3. Запуск бэкенда
Запустите сервер Node.js:
```bash
node server.js
```

### 4. Открытие в браузере
```bash
http://localhost:5000
```



### Введите IP-адрес вашего Linux-сервера, логин (например, root) и пароль для авторизации. Приложение готово к работе!
